# مدينة المهام

تطبيق Android أصلي يحوّل إنجاز المهام إلى مدينتين ثلاثيتي الأبعاد.

## النسخة 1.0

- مدينة للمهام العادية بلا وقت محدد.
- مدينة مستقلة للمهام الضرورية بمؤقت من دقيقة إلى 6 ساعات.
- إكمال المهمة يبني بيتًا جديدًا مع حركة بناء.
- انتهاء مهمة ضرورية يهدم بيتًا موجودًا مع حركة تحطم.
- تدوير المدينة بالسحب والتكبير والتصغير بإصبعين.
- حفظ المهام وعدد البيوت محليًا دون إنترنت.
- تطبيق Java + OpenGL ES 2.0 أصلي؛ لا HTML ولا WebView ولا Godot.

## تنزيل APK

افتح تبويب **Actions**، ثم أحدث عملية بناء ناجحة، وحمّل الملف
`task-city-v1.0-apk` من قسم **Artifacts**.
