# مدينة المهام

تطبيق Android أصلي يحوّل إنجاز المهام إلى مدينة كرتونية تفاعلية.

## معاينة البيئة v2.0

- كاميرا مائلة ثابتة مثل ألعاب بناء المدن، مع سحب في أربعة اتجاهات.
- تكبير وتصغير بإصبعين وحدود تمنع ظهور نهاية الخريطة.
- سماء متدرجة وشمس وسحب وتلال وأشجار وظلال كرتونية.
- طرق وأرصفة وحدائق و25 قطعة جاهزة لاستقبال نماذج البيوت.
- بيئة نهارية للمهام العادية وبيئة ليلية للمهام الضرورية.
- حفظ المهام والتقدم محليًا دون إنترنت.
- Java وOpenGL ES 2.0 أصلي؛ لا HTML ولا WebView ولا Godot.

## تنزيل APK

افتح تبويب **Actions**، ثم أحدث عملية بناء ناجحة، وحمّل الملف
`task-city-v2.0-apk` من قسم **Artifacts**.
