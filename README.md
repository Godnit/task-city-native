# مدينة المهام

تطبيق Android أصلي يحوّل إنجاز المهام إلى مدينة كرتونية تفاعلية.

## معاينة البيئة v2.3

- أرض عشب كرتونية مفتوحة بلا طرق أو أرصفة أو قطع بناء ظاهرة.
- إضاءة شمس اتجاهية على الخريطة دون قرص شمس مرسوم في الخلفية.
- أشجار مستديرة موحّدة بجذوع أسطوانية ومسافات متساوية.
- ظلال هندسية حقيقية للشجر والسور مسقطة على أرض العشب.
- كاميرا مائلة ثابتة مع سحب في أربعة اتجاهات.
- تكبير وتصغير بإصبعين من دون تحريك مركز الخريطة.
- حدود وأرض احتياطية واسعة تمنع ظهور نهاية الخريطة.
- بيئة نهارية للمهام العادية وبيئة ليلية للمهام الضرورية.
- حفظ المهام والتقدم محليًا دون إنترنت.
- Java وOpenGL ES 2.0 أصلي؛ لا HTML ولا WebView ولا Godot.

## تنزيل APK

افتح تبويب **Actions**، ثم أحدث عملية بناء ناجحة، وحمّل الملف
`task-city-v2.3-apk` من قسم **Artifacts**.
