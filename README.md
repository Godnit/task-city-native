# Hand Gesture Cube Controller v1.6 Android 8

تطبيق Android أصلي مستقل لاختبار تتبع اليد بالكاميرا الأمامية والتحكم بمكعب دون لمس الشاشة.

## الوظائف

- يرسم 21 نقطة وخطوط معالم اليد فوق صورة الكاميرا.
- يوضح حالة الأصابع الخمسة: مفتوح أو مثني.
- يتعرف على الكف والقبضة و👌 و✌️ و🤟.
- ينعّم خطوط اليد على معدل تحديث الشاشة مع إبقاء استجابة الحركة سريعة.
- يمنع وميض الخطوط عند فقد نتيجة واحدة عابرة من النموذج.
- يبقي المكعب ثابتًا حتى ضم الإبهام والسبابة بحركة 👌.
- يحرك المكعب مع نقطة الإمساك فقط، ثم يثبته عند فتح الإصبعين.
- يعمل دون إنترنت بعد التثبيت.
- يستهدف Android 8.1 وما بعده، بالوضع الطولي.
- يستخدم CameraX وMediaPipe Tasks الأصليين بدل WebView وWASM.
- يستخدم إصدار MediaPipe مستقرًا متوافقًا أصلًا مع Android 8 بدل تعديل مكتبة 1.0.0 الثنائية.
- يعرض سرعة المتتبع الفعلية ورسالة تشخيص واضحة إذا تعذر تحميل النموذج.
- نسخة خفيفة مخصصة لهاتف المستخدم ذي معمارية `armeabi-v7a`، دون مكتبات المحاكي أو معمارية 64 بت غير المستخدمة.

## البناء

يُبنى APK تلقائيًا عبر GitHub Actions عند رفع الملفات إلى الفرع `main`.
